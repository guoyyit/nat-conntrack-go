# nat-conntrack-go

本地网络地址转换（NAT）与连接跟踪（conntrack）库。对经过的 IPv4 报文完成
地址与端口改写并维护会话状态，保证双向流量正确回流。报文输入输出使用本地
内存管道模拟，不依赖真实网卡或外部服务。

## 包结构

| 包          | 职责                                                         |
| ----------- | ------------------------------------------------------------ |
| `packet`    | IPv4/TCP/UDP/ICMP 解析、校验和验证、改写后序列化             |
| `conntrack` | 基于五元组的连接跟踪表、会话状态机、超时回收与容量淘汰       |
| `nat`       | NAT 引擎：SNAT/反向改写、端口分配、分片缓存、统计            |
| `pipe`      | 本地内存报文管道，模拟报文输入输出                           |

## 地址与端口改写

- 出站（`DirOutbound`）：源地址改写为出口公网地址，源端口改写为映射端口（SNAT）。
- 入站（`DirInbound`）：命中会话的回程五元组后，目的地址/端口反向改写回内网主机。
- 改写后 IP 首部校验和全量重算；TCP/UDP 校验和按 RFC 1624 增量更新，
  因此对仅含首片的分片报文同样正确；ICMP echo 以 identifier 充当“端口”参与映射。
- 映射端口优先保留原始源端口，冲突时取范围内最小空闲端口（确定性、可复现）。

## 会话状态机

```
                SYN(去程首包)            SYN-ACK / ACK / 回程包
   (创建) ───────────────► NEW ──────────────────────────► ESTABLISHED
                              │                                │
                              │ RST                            │ FIN / RST
                              ▼                                ▼
                           CLOSED ◄──── 双向 FIN / RST ──── CLOSING
```

- **NEW**：去程首包建表。TCP 重传 SYN 幂等；乱序 ACK 宽容迁移到 ESTABLISHED；
  UDP/ICMP 见到回程包后进入 ESTABLISHED。
- **ESTABLISHED**：双向数据阶段。TCP 进入此状态时超时提升为 2 小时。
- **CLOSING**：任一方向出现 FIN，超时缩短为 30 秒。
- **CLOSED**：双向 FIN 或 RST。此状态上的报文属于非法迁移，
  以 `ErrInvalidState` 拒绝且不修改任何状态；表项保留 10 秒后由回收清理。

重复与乱序报文的状态迁移是幂等的，不会产生错配或状态污染。

## 超时与容量策略

| 协议/状态       | 默认超时 |
| --------------- | -------- |
| TCP ESTABLISHED | 2 小时   |
| TCP CLOSING     | 30 秒    |
| TCP CLOSED      | 10 秒    |
| UDP             | 3 分钟   |
| ICMP            | 30 秒    |
| 分片缓存        | 30 秒    |

- 每条表项以 `LastSeen + Timeout` 判定超时；`Engine.Reap()` 回收超时表项
  并释放对应映射端口，同时清理过期分片缓存。
- 容量满时的建表策略：先回收已超时表项，再淘汰最久未活跃（LRU）表项，
  仍不足时返回 `ErrTableFull`。不会误删活跃会话，也不会无限增长。
- `Engine.Close()` 清空会话表并释放全部端口，异常或重启后不残留半建立状态。

## 异常链路（可区分的拒绝原因）

| 错误                     | 含义                                   |
| ------------------------ | -------------------------------------- |
| `ErrChecksumInvalid`     | IP 首部或传输层校验和验证失败          |
| `ErrMalformedPacket`     | 报文截断、长度字段非法等               |
| `ErrProtocolUnsupported` | 非 TCP/UDP/ICMP，或不支持的 ICMP 类型  |
| `ErrNoSession`           | 入站报文或后续分片无对应会话           |
| `ErrInvalidState`        | 非法状态迁移（如已关闭会话上的报文）   |
| `ErrTableFull`           | 会话表满且无法淘汰                     |
| `ErrNoPortAvailable`     | 映射端口范围耗尽                       |
| `ErrPortInUse`           | 指定端口已被占用                       |

所有拒绝都不修改会话状态，后续报文仍可正常处理。

## 并发与可观测性

- 连接跟踪表、端口分配器、分片缓存各自内建锁，统计计数使用原子操作，
  支持高并发读写；同一会话并发建表只会产生一条表项与一个映射端口。
- `Engine.Stats()` 返回会话数、活跃端口数、收发/拒绝计数等一致快照。

## 测试

```sh
go test -race ./...
```

覆盖：分片（含乱序分片）、乱序与重复报文、超时回收与端口释放、
端口冲突与耗尽、畸形/不支持/非法状态报文、并发会话与统计一致性、
内存管道端到端双向回流。
